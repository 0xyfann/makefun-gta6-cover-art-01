# Afterglow Cover Studio

Turn your photos into an original, sunset-graded collage with slanted panels and large, layered lettering. Built for [Make GTA 6 Cover Art](https://make.fun/bounty/gta6-cover-art-01).

## Make a cover

1. Open `app/index.html` in desktop Chrome, or run `node serve.ts` and visit `http://localhost:8080`.
2. Add or drop photos. One photo fills the whole collage. With several photos, choose which goes in each panel.
3. Edit the headline and small print, choose a grade and format, then select a panel to drag its photo, zoom, or fine-tune the crop.
4. Select **Export PNG** for a 1080 × 1080, 1080 × 1350, or 1920 × 1080 cover.

The editor works entirely offline. It reads photos locally and does not upload them. The deck of demo photos includes the two AI-generated images supplied for reuse in the competition kit and original generated illustrations.

## Build the dossier

```sh
MAKEFUN_OUTPUT_DIR=/tmp/afterglow-output node main.ts
```
